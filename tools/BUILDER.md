# FLOOR777 島図ビルダー v2

## 決定仕様

家で「位置・形・台数」だけ作成してストックし、現地では台番号をまとめて入力します。番号を推測して確定データとして出力しません。

1. `tools/hall-editor.html` を開く。
2. 店舗名・店舗ID・地域を設定し、PNG/JPEG/WebPの島図画像を読み込む。
3. 「島を自動検出」で候補を確認して追加。直線・斜め・曲線・円形のボタンで手動追加も可能。
4. 島の位置・台数・台サイズ・間隔・角度・半径を調整する。単台移動をONにすれば個別調整できる。
5. 配置を確認した島は「配置・形・台数を確認済み」を選び「島の設定を反映」。番号は空欄でよい。
6. 画像込みで端末内に自動保存される。「プロジェクト保存」でJSONバックアップ。「島だけ保存」は番号を除いたコピーを出力し、編集中の番号は残す。
7. スマホの「現地で台番号入力」へ切替。島をタップし、開始番号・台数・方向を指定。図の①と矢印が順方向の目印。
8. 欠番は「飛ばす番号」、例外は「番号を直接指定」で修正する。「入力して次の未入力島へ」で連続入力できる。
9. 「完成チェック」が未入力・重複・配置確認待ち・台の重なり・範囲外・店舗情報を確認する。
10. 「FLOOR777用 JSON一式」で単一ZIPを保存する。

## 画像の自動検出

ブラウザ内の色領域検出・主軸分析・円フィッティングで直線／曲線／円形の**候補**を作ります。画像を外部に送信しません。図の色・線・解像度によって島の結合・分割・見落としが生じます。色のない写真や細かい台列では手動追加を使ってください。台数は推定であり、すべての検出候補を未確認として追加します。OCRで台番号を確定する機能はありません。元画像を見て台数と形を直し、現地で番号を入力する設計です。

画像は最大20MBで、長辺2400pxに縮小して保存します。検出は長辺ではなく横幅900px以下の作業画像を使います。下敷き画像の縦横比とキャンバスを別に変更した場合も検出座標を変換します。

## 保存とオフライン

- IndexedDBへプロジェクト別に画像・島・番号を保存します。複数店舗を切替・複製・削除できます。
- オフラインで編集・採番・保存・書き出し可能。初回にHTTPSまたはlocalhostで開き、「この端末でオフライン利用できます」の表示を確認してください。
- スマホへ渡す際は「プロジェクト保存」のJSONを送って読み込みます。端末間の自動同期はありません。
- ブラウザのサイトデータ削除で端末内の保存も消えます。持ち出し前にプロジェクトJSONを保存してください。
- 台数変更時は採番済みの番号消去を確認します。未反映の入力欄は「島の設定を反映」で確定します。
- Undo/Redoは最大60操作。同一店舗の複数タブ同時編集は避けてください。

## FLOOR777への組み込み

この変更は公開repoの `tools/` とテストのみです。既存の店舗座標、営業データ、広告設定は含みません。

出力ZIPには以下が入ります。

- `data/positions-<id>.json`: 既存互換の `{台番号:[x,y,width,height]}`
- `data/<id>.json`: 店舗・台番号・機種名
- `registration.json`: `data/halls.json` への追加情報（draft）
- `collector-entry.json`: みんレポURLを設定した場合の収集設定
- `layout-draft.json`: ビルダーv2の設定。画像は除外
- `CHECKLIST.md`: 公開前の確認

既存の生成CLIはv2と従来のrows形式の両方を受け付けます。

```sh
node tools/build-hall.mjs layout-draft.json --out /absolute/path/new-output
```

店舗ページを含む一式を生成します。出力先が存在する場合は上書きを拒否します。ZIPを出力しただけでは本番登録・収集は始まりません。生成ページはdraft/noindexで、機種名・台数・現地配置を照合してから公開してください。

従来の列エディターは `tools/hall-editor-legacy.html` に保存しています。旧rows形式のJSONは新ビルダーにも読み込めます（配置を再確認してください）。

## 開発・検証

```sh
python3 -m http.server 8000
# http://localhost:8000/tools/hall-editor.html
node tests/builder-model.mjs
node tests/hall-template.mjs
npm install
npx playwright install chromium
node tests/builder-browser.cjs
```

ブラウザテストはローカルサーバーを起動し、PC/390px画面・一括入力・逆順・飛び番・重複拒否・画像検出・複数保存・オフライン再読込・ZIP出力を検証します。iPhone実機の検証を代替するものではありません。
